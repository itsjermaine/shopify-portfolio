FEATURED PROJECT / CELLUMOVE

A custom feature.
Built into the theme.

View live page ↗

I implemented the layout and design of Cellumove’s Sculpt & Smooth V2 product page, including a reusable “Frequently Bought Together” section that was not available in the existing theme.

The challenge

The existing theme did not include this feature. It needed a custom implementation that could be reused throughout the theme.

My contribution

Built the section in the theme code, exposed editable fields for visual content management, and added variant selection and quick add-to-cart for the selected products.

The result

A reusable theme feature with editable content that lets shoppers select product options and add items to their cart directly from the section.

Custom theme development Reusable section Quick add-to-cart Editable fields Layout implementation
